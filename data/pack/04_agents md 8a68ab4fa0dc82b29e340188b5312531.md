# 04_agents.md

**Document ID:** RP-KB-04

**Effective:** 2026-03-01

RiverPay agents are independent outlets. They are not RiverPay employees.

## Find an agent

In the app: Map → Agents. On USSD: `*123*4#` returns the nearest three agent codes if location SMS is enabled. This handbook does not contain a live agent list.

## Cash-in

1. Show the agent your RiverPay number.
2. Hand over cash.
3. Confirm the SMS or in-app credit **before** you leave.
4. Customer fee: **free** (see current fees document).

Agents cannot credit a frozen wallet. They cannot complete KYC.

## Cash-out

1. Generate a **6-digit cash-out code** valid for **15 minutes**.
2. Tell the agent the code. Do not shout it in a queue.
3. Agent pays cash after their terminal shows success.
4. Customer fee: see **current** cash-out fee.

If the agent’s float is empty, they cannot pay you. Try another agent. The assistant cannot top up agent float.

## Agent misconduct

RiverPay staff and agents will **never** ask for your PIN. If an agent asks for your PIN, cancel, leave, and call the contact center.
